│                                                                           │

4. SHARING INSTRUCTIONS FOR TEAM LEADS
================================================================================

TO SHARE WITH NEW TEAM MEMBERS:

✅ Option A: Secure Cloud Storage
   1. Upload the 3 Firebase files to Google Drive / OneDrive
   2. Share the link with team members (use "Anyone with link" or specific emails)
   3. New members download and place files in correct directories

✅ Option B: Encrypted Email
   1. Zip the 3 Firebase files
   2. Encrypt the zip file (Windows: Right-click → Properties → Advanced)
   3. Send via email with password separately

✅ Option C: Secure Password Manager
   1. Upload files to Bitwarden / 1Password
   2. Share access with team members
   3. Team members download and place files

⚠️  NEVER share via unencrypted email or public channels

6. WHY ARE THESE FILES NOT IN GIT?
================================================================================

These files are in .gitignore because:

1. ✅ SECURITY: They contain API keys and sensitive credentials
2. ✅ ENVIRONMENT-SPECIFIC: Each Firebase project is different
3. ✅ TEAM-SPECIFIC: API keys should never be public
4. ✅ BEST PRACTICE: Follow Google & Flutter official recommendations

7. COMMON ERRORS & SOLUTIONS
================================================================================

ERROR: "FileSystemException: Cannot open file"
CAUSE: firebase_options.dart is missing
FIX:
  - Ask team lead for lib/firebase_options.dart
  - OR run: flutterfire configure

ERROR: "Gradle build failed. Build file does not exist"
CAUSE: android/app/google-services.json is missing
FIX:
  - Ask team lead for android/app/google-services.json
  - OR download from Firebase Console

ERROR: "Build input file does not exist"
CAUSE: ios/Runner/GoogleService-Info.plist is missing
FIX:
  - Ask team lead for ios/Runner/GoogleService-Info.plist
  - OR download from Firebase Console

## TROUBLESHOOTING

### Problem: Can't find the API keys
```
Solution:
1. Make sure you're in the right project (seating-arrangement-73a5d)
2. Go to: APIs & Services → Credentials
3. Scroll down to "API Keys" section
4. If still not visible, check under "API Key (Legacy)" section
```

### Problem: Can't delete - "Permission denied"
```
Solution:
1. You need "Owner" or "Editor" role in the project
2. Ask your Google Cloud account owner for permission
3. Or create a new Firebase project (if you're not the owner)
```

### Problem: App still doesn't work after deletion
```
Solution:
1. Give it 5-10 minutes for Google to sync
2. Run: flutter clean && flutter pub get && flutter run
3. Check Firebase console for any error messages
4. Verify new API keys exist and are enabled
5. If still issues, regenerate with: flutterfire configure
```

### Problem: Gemini API still shows "suspended"
```
Solution:
1. Wait 1-2 hours for Google to process deletion
2. You should get an email notification when cleared
3. Check Google Cloud console for status updates
4. If still suspended after 2 hours, submit appeal
```
